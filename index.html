✦ Conceito Bootstrap & UI Moderna

O que é o Bootstrap?
É um framework front-end de código aberto que oferece componentes prontos (como Modals, Alerts, Buttons e Grid System) e classes utilitárias para acelerar a criação de interfaces responsivas.

Como aplicamos na Versão 5:
Nesta versão, aplicamos os conceitos visuais e de usabilidade dos componentes .alert e .modal do Bootstrap utilizando CSS customizado e variáveis dinâmicas, mantendo a identidade visual exclusiva do projeto sem bloqueios na tela.
